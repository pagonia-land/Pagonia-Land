# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**, as its code of conduct for all participants in project spaces (issues, pull requests, discussions, and any official chat channels).

The full text is available at:

- <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

Please read it before participating. By contributing to this project, you agree to abide by its terms.

## Reporting

If you experience or witness behaviour that violates the Code of Conduct, please report it to the project maintainers via a private channel:

- A private GitHub security advisory works for confidential reports — see [SECURITY.md](SECURITY.md) for the link. Note in the report that it is a Code of Conduct matter, not a security vulnerability.
- A private direct message to a maintainer on the project's community chat, if one is set up.

All reports will be reviewed and investigated promptly and fairly. Maintainers are obligated to respect the privacy and security of the reporter.

## Scope

This Code of Conduct applies within all project spaces and also applies when an individual is officially representing the project in public spaces.

## Enforcement

Maintainers are responsible for clarifying and enforcing the standards described in the Contributor Covenant. They may take any action they deem appropriate, including warning, temporary or permanent ban, or removal of contributions, for behaviour they consider inappropriate, threatening, offensive, or harmful.

The full enforcement guidelines, including the four-step escalation ladder (Correction → Warning → Temporary Ban → Permanent Ban), are defined in the upstream Contributor Covenant text linked above.
