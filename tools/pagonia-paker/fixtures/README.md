# Paker Fixtures

This folder is reserved for Pagonia Land Paker test fixtures.

Fixtures are **built at test time** from in-process byte buffers, not copied from real game data. That keeps the repository free of any extracted `.pak` content and makes the tests reproducible without a game install.

Any fixture files that do appear here are small, artificial archives generated by helper code in the test project — for example a 2-entry pak with one compressed and one uncompressed file.

Real `.pak` files from a Pioneers of Pagonia install must never be committed.
